FAQ

Pertanyaan yang Sering Diajukan

1. Apakah bisa pakai foto struk di paket Starter?

Tidak. Fitur ekstraksi foto struk dengan AI Vision OCR adalah fitur eksklusif untuk pengguna paket Pro. Pengguna Starter dapat mencatat pengeluaran melalui teks dan rekaman voice note di Telegram.

2. Bagaimana keamanan data transaksi saya di TataDana?

Data Anda 100% tersimpan aman di database Supabase Postgres dengan Row Level Security (RLS) terisolasi per akun. API token terenkripsi dan file export disimpan dalam bucket privat dengan signed URL bertenggang waktu.

3. Apakah saya perlu membuat bot Telegram sendiri di @BotFather?

Secara default, Anda langsung dapat memakai bot resmi TataDana (@TataDanaOfficialBot) hanya dengan memverifikasi nomor HP Anda. Namun, jika Anda ingin memiliki bot pribadi eksklusif atas nama Anda sendiri, Anda bisa memasukkan token bot dari @BotFather di tab Settings.

4. Bagaimana format nominal yang dikenali bot?

Bot mengenali semua format bahasa natural Indonesia: "15rb", "15ribu", "15k", "1.5jt", "1,5jt", "500k", dan angka biasa seperti "25000".

5. Apa yang terjadi jika transaksi Starter saya mencapai batas 50 transaksi?

Bot akan memberikan notifikasi bahwa limit transaksi bulan berjalan telah tercapai beserta ajakan upgrade ke paket Pro Unlimited. Transaksi lama tetap tersimpan utuh dan dapat dilihat di dashboard.

6. Metode pembayaran apa saja yang didukung?

Kami mendukung pembayaran otomatis instan via Midtrans (QRIS, Virtual Account BCA/Mandiri/BRI, GoPay, ShopeePay) serta opsi transfer manual yang dapat diverifikasi oleh admin.

7. Apakah jam transaksi dan reminder menggunakan Waktu Indonesia Barat (WIB)?

Ya, seluruh timestamp transaksi, ringkasan harian, dan notifikasi reminder bot diset menggunakan zona waktu Asia/Jakarta (WIB).
